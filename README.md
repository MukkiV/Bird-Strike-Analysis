# 🛫 Aircraft Wildlife Strike Analysis

## 📌 Project Description
This project analyzes aircraft wildlife (bird) strike data to understand safety risks, operational impact, and cost patterns in aviation. The analysis focuses on identifying trends in strike occurrences, damage frequency, high-risk flight phases, and financial impact across aircraft types.

The project uses cleaned strike records, structured analysis, and visual dashboards to study how wildlife strikes affect aviation safety and operations.

---

## 📂 Project Files
- **Bird_strike_cleaned.csv** – Cleaned dataset derived from aircraft wildlife strike records  
- **Data Cleaning.ipynb** – Jupyter Notebook used for data cleaning and preparation  
- **Comprehensive-Analysis-of-Aircraft-Wildlife-Strikes.pptx** – Presentation summarizing analysis and findings  
- **Final Project - 1.twbx** – Tableau dashboard (analysis view)  
- **Final Project - 2.twbx** – Tableau dashboard (summary view)

## 🔍 Scope of Analysis
- Cleaning and standardizing wildlife strike records  
- Year-wise trend analysis of total and damaging strikes  
- Airport-level strike concentration analysis  
- Species-level analysis of damaging strikes  
- Flight phase risk analysis (approach, landing, etc.)  
- Cost impact analysis by aircraft model  

---

## 📈 Key Insights
- Total reported wildlife strikes increased steadily between **2000 and 2010**, while damaging strikes remained a small proportion.
- **Approach and landing phases** account for the highest number of wildlife strike incidents.
- Large bird species and **unknown bird categories** contribute most to damaging strikes.
- A small number of aircraft models account for a **large share of total repair costs**, with models such as **Learjet-60 and B-767-300** showing the highest impact.
- When pilots were warned, the damage rate reduced from **9.57% to 7.82%**, showing measurable risk reduction.
